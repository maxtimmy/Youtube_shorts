# Roadmap

Roadmap отражает безопасное развитие продукта. Сроки намеренно не обещаны.

## P0 — воспроизводимая основа

- [x] Добавить безопасный экспорт обезличенных n8n workflow в каталог `workflows/`.
- [x] Описать и мигрировать схемы `media-library.sqlite` и `youtube-publishing.sqlite`.
- [x] Добавить smoke-тест API dashboard на временных базах.
- [x] Убрать зависимость панели от Docker socket и внутренней БД n8n.
- [x] Добавить резервное копирование и восстановление прикладного состояния.

## P1 — provenance и ручная проверка

- [ ] Ввести карточку источника: URL, автор, лицензия, дата проверки, разрешённые способы использования.
- [ ] Хранить сценарий, промпты, используемые ассеты и историю преобразований для каждого ролика.
- [ ] Добавить обязательный rights/policy/quality approval до попадания в очередь публикации.
- [ ] Ввести обнаружение дубликатов внутри собственной медиатеки.
- [ ] Добавить журнал действий и понятное удаление данных.

## P2 — исследование трендов

- [ ] Подключать только разрешённые API и источники данных с соблюдением их условий.
- [ ] Сохранять агрегированные сигналы: тема, формат, темп, длительность, интерес аудитории.
- [ ] Исключить скачивание чужих роликов и перенос сценария/монтажа «кадр в кадр».
- [ ] Добавить scoring идей с учётом новизны и соответствия выбранной аудитории.

## P3 — управляемая публикация и аналитика

- [ ] Начать с ручной публикации и ограниченного пилота на одном канале.
- [ ] Добавить квоты, идемпотентность и безопасные повторы без дублей.
- [ ] Сопоставлять результаты с версией идеи и creative brief, а не только с аккаунтом.
- [ ] Автоматизировать публикацию лишь после подтверждения прав и стабильности пилота.

## Вне scope

- перезалив или минимальная переработка чужих видео;
- обход API, CAPTCHA, rate limits и модерации платформ;
- автоматизированный спам, накрутка и управление сеткой аккаунтов для обхода ограничений;
- клонирование голоса или внешности реального человека без согласия.
